Privacy Policy

Last updated: 2026-08-10

Live Photo Collage is open-source, self-hosted software — not a service run by its developer. This page (a static landing page at this GitHub Pages address) collects nothing at all; it has no analytics, no cookies, and no forms. This policy instead explains what the software does with data, once someone deploys and runs their own instance of it.

There is no hosted service

The developer does not operate a public instance of Live Photo Collage and does not receive, store, or process any photos, account information, or other data on anyone's behalf. Anyone who wants to use the app deploys their own instance — on their own server, container, or Kubernetes cluster — using their own Google OAuth client. That deployer is the operator of their instance and is responsible for it, including for complying with any privacy laws that apply to their use of it.

What a running instance stores, and where

All of the following stays on the infrastructure the operator deploys the app to. None of it is sent to the developer of this project or to any third party other than Google, for sign-in.

  • Google account info — when someone signs in, the app reads their Google profile (name, email, profile picture) via Google Sign-In to create or look up their board.
  • Phone number (optional) — a signed-in user may add a phone number to their own profile; it's stored alongside their account and is never required.
  • Uploaded photos — stored on the instance's local disk, date-partitioned, with ownership of each photo tracked in a local SQLite database. Guests upload without signing in; only the board's owner (and any admin the operator configures) can view, download, or delete them.

What the software does NOT do

  • It does not include any advertising SDK, analytics SDK, or third-party tracker.
  • It does not share photos, profile data, or phone numbers between boards — each board is only ever visible to its owner and the operator's configured admins.
  • Guests uploading via a QR code are never asked to sign in, and no personal data is collected from them beyond the photo file itself.

Google Sign-In

Sign-in uses Google's own Sign-In flow. Google's handling of the credentials involved is governed by Google's privacy policy, not by this project.

Changes to this policy

If this policy changes, the updated version will be posted at this same location with a new "Last updated" date.

Contact

Questions about this project can be raised via its issue tracker. For questions about a specific deployment's handling of your data, contact whoever operates that instance.
